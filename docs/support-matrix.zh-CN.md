# 支持与验证矩阵

这份矩阵区分自动化证据与平台验收。一次本地测试通过，并不代表所有桌面环境都已真机验证。

当前托管基线为 `@deepseek-ai/dsh@0.1.7-rc.2`。发布前，CI 会从空目录安装带完整性锁定的
依赖图，并启动一个需要认证的真实 Web Profile。

| 项目 | Windows | macOS | Linux |
| --- | --- | --- | --- |
| Rust 与前端单元测试 | CI 与本地 | CI 构建目标 | CI 构建目标 |
| 隐藏子进程启动 | `CREATE_NO_WINDOW` 合同 | 原生进程路径 | 原生进程路径 |
| Harness 托管与就绪检测 | 自动化 | 自动化 | 自动化 |
| 安装升级冒烟 | 可选有状态 Windows runner | 需要签名 macOS runner | 需要发行版 runner |
| 真机显示、睡眠唤醒、防火墙 | 需要设备测试 | 需要设备测试 | 需要设备测试 |

## 报告问题

请附 Studio 版本、系统版本、所选 Profile、准确操作、时间戳和脱敏诊断导出。
不要附 API 密钥、配对凭据、主目录机密或完整环境变量转储。
