# DSH Studio 能力与质量路线图

[English](ROADMAP.md)

更新于 2026-09-29，已发布基线为 v0.9.19。开发中的项目只有进入正式发布版本的更新日志
后，才属于已发布功能。本文件记录产品能力与验收边界，不以相对排名或“零缺陷”承诺
代替实际证据。

## 已交付

| 范围   | 当前能力                                                   | 边界                                                             |
| ------ | ---------------------------------------------------------- | ---------------------------------------------------------------- |
| 运行时 | 受监管的 Harness、Node 选择/安装、轻量版和完整离线资源     | 下载成功不等于启动成功，仍须通过冷启动和打包资源门禁             |
| 启动   | 渲染器看门狗、静态恢复、安全模式                           | 常规页面无法挂载时仍须保留可用恢复入口                           |
| 配置   | 新建、复制、重命名、比较、导入导出和跨窗口切换             | 校验备份完整性，选中配置不代表已经成功启动                       |
| 插件   | 响应式市场、多来源、搜索/筛选/分页、压缩包导入和已安装版本 | 精确版本审查、兼容性检查、一次性意图、回执和恢复；安装不代表激活 |
| 合同   | Protocol 3 桌面桥和只读 Host Protocol 1                    | 公开宿主服务不开放任意桌面 IPC、原生句柄或命令执行器             |
| 会话   | 本地搜索、项目筛选、记录、归档及 Markdown/HTML/JSON 导出   | 以本地数据为准                                                   |
| 用量   | 按模型定价、月预算、逐日趋势和 CSV 导出                    | 使用用户填写的价格，未定价模型不视为免费                         |
| 终端   | 真实 PTY、Unicode、复制粘贴、多标签和进程管理              | 异常退出保留记录，退出应用时结束子进程                           |
| 工作区 | 目录选择、磁盘准入、Git 工作树发现和创建                   | 不自动删除有未提交修改或由外部创建的工作树                       |
| 远程   | 独立 LAN 网关、短期配对和按设备撤销凭据                    | Harness 保持回环监听，不等于已内置公网隧道                       |
| 界面   | 三种展示模式、多窗口、命令面板和浅色/深色/跟随系统主题     | 键盘与模态语义、减少动画和强制颜色样式                           |
| 诊断   | 有界脱敏报告、轮转日志、崩溃证据和导出                     | 排障报告不代表自动收集遥测                                       |
| 更新   | 签名更新包、绑定审查版本的确认和回退清单                   | 更新包签名不等于操作系统发布者签名                               |
| 分发   | Windows/macOS/Linux 发布任务和包渠道清单                   | 生成清单不代表已经进入所有外部软件仓库                           |

详细合同见[架构](architecture.zh-CN.md)、[使用指南](user-guide.zh-CN.md)和
[插件互操作](plugin-interoperability.zh-CN.md)。

## v0.9.19 已交付

- 已登记工作树的只读审阅，区分已暂存/未暂存差异、显示未跟踪路径、限制输出，覆盖
  键盘与焦点回归，不提供破坏性 Git 操作。

- 单窗口、左右分屏、上下分屏和四宫格终端布局，切换布局保留进程身份和输出。
- 原生持久保存主题、界面模式、侧栏、引导、定价、忽略的更新和终端布局；重启时随机回环
  端口变化不应丢失偏好。拒绝未知设置项，损坏文件不能被直接覆盖。
- 真实 WebView 终端回归，覆盖 5 个实际 PTY、页面往返、异常退出记录、尺寸更新安全性
  和右键菜单目标。

这些变化通过跨平台发布门禁后，已随 **0.9.19** 正式交付。单元测试、原生命令检查和 Windows WebView 验收
属于不同证据，不能单独代替最终安装器或 macOS 真机验收。

## 开发中

以下优先项属于后续工作，不作为 v0.9.19 已交付能力。

## 后续优先项

### 可靠性与完整操作流程

- 按页面维护加载、空状态、成功、失败、取消、重试、键盘、小窗口和两种主题的检查表。
- 验证全新安装及保留配置、插件、偏好、会话的升级，覆盖原生选择器、托盘和退出流程。
- 分别检查配置组合、后端加载、客户端发现和界面挂载，不绕过兼容性保护来消除警告。
- 验证长会话及反复切页、切换配置和终端操作后的响应性与资源清理；堆内存采样不能单独
  证明不存在泄漏。

### 工作区与内容能力

- 提供移除、破坏性合并或回滚前，先补齐持久工作树所有权和中断恢复。
- 完善工作区/会话关联及文件、差异、测试证据审查。记住布局不等于恢复进程，也不等于
  已经具备安全合并合同。
- 按实际格式、权限、依赖和打包运行时需求评估文档预览、可编辑演示文稿和图像工具。
  市场中存在插件，不代表相关流程已经完成集成和测试。
- 评估可选公网访问时，必须包含显式开启、认证配对、资源/速率限制和撤销机制，不直接
  暴露 Harness 原始端口。

### 分发与真机实证

- 凭据具备后，在实际产物上验证 Windows 发布者签名及 macOS Developer ID/公证。
- 区分 Intel/Apple Silicon 真机验收与 CI 编译结果。
- 宣传渠道可用前核实外部软件仓库实际状态。
- 镜像必须保持原字节，并提供可独立验证的校验和及签名；临时代理不是官方镜像。

## 发布门禁

1. 检查工作树、上一版本、更新日志和本次提交，只暂存本任务文件，不提交无关本地资料。
2. 前端/原生测试及覆盖率、严格 Clippy、lint、生产构建、公开合同、无障碍和双语文档门禁通过。
3. 在隔离数据上做多轮真实界面及原生检查，记录失败、修复、复测，以及因凭据或硬件缺失
   而未验收的流程。
4. 跨平台冷启动和打包资源流水线检查通过。
5. 核验发布资产、校验和、更新清单及签名状态；Release 说明具体已验证变化和限制。

耗时、单元测试通过与安装包上传不能互相替代。存在已知阻断回归时不得发布。
